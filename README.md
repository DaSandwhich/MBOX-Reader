# MBOX Reader

A Gmail-style offline MBOX email reader built with Python.

## Features

- Read large MBOX email archives
- Gmail-style conversation viewing
- Advanced email search
- Custom labels and folders
- Attachment management
- PDF and EML exports
- Duplicate email detection
- Saved email archives

## Requirements

- Python 3
- ReportLab for PDF exports

## Installation

Install the required dependency:

    py -m pip install reportlab

Run the application:

    py mbox_reader_pro.py

## Development Goals

- Improve application responsiveness
- Organize code into separate modules
- Add clear comments and docstrings
- Improve database and search performance
- Maintain compatibility with large archives

## Privacy

Email archives, attachments, and local databases
should not be committed to this repository.
